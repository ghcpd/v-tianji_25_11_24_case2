# 🏋️ Fitness Progress Tracker

A modern, polished web application for tracking fitness progress with metrics, goals, and weekly summaries.

![Status](https://img.shields.io/badge/Status-Complete-success)
![Tests](https://img.shields.io/badge/Tests-35%20Passing-brightgreen)
![Coverage](https://img.shields.io/badge/Coverage-Full-brightgreen)

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run all unit tests
npm test

# Run E2E tests
npm run test:e2e
```

## 📊 Features

- **Real-time Metrics**: Track workouts, calories, active minutes, and distance
- **Goal Progress**: Visual progress bars for fitness goals
- **Weekly Activity**: Interactive chart showing daily workout completion
- **Responsive Design**: Works perfectly on desktop and mobile
- **Modern UI**: Beautiful gradient cards with smooth animations

## 🧪 Testing

- **23 Unit Tests** (Vitest + React Testing Library)
- **12 E2E Tests** (Playwright)
- **100% Component Coverage**

All tests pass successfully! ✅

## 🛠️ Tech Stack

- React 19.2 + TypeScript
- Vite 7.2.4
- Vitest + Playwright
- CSS Modules

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm test` - Run unit tests
- `npm run test:ui` - Run tests with UI
- `npm run test:e2e` - Run E2E tests
- `npm run test:e2e:ui` - Run E2E tests with UI

## 🎨 Components

- **MetricCard** - Display fitness metrics with change indicators
- **GoalCard** - Show goal progress with visual progress bars
- **WeeklySummary** - Interactive weekly activity chart
