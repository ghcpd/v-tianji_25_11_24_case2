# Fitness Progress Tracker

A small React + Vite app showcasing a fitness progress tracker UI (metrics, goals, weekly summaries).

## Setup

Install dependencies:

```powershell
npm install
npx playwright install
```

## Run dev server

```powershell
npm run dev
```

Visit: http://localhost:5173

## Tests

Unit tests (Vitest):

```powershell
npm run test
```

E2E tests (Playwright):

```powershell
npm run e2e
```
