### Project overview
- **Stack:** React 19 + Vite + TypeScript, Tailwind CSS, Recharts, Lucide icons.

- **Testing:** Vitest + Testing Library (unit/coverage), Playwright (E2E).

- App.tsx — main dashboard
- components — `MetricCard`, `GoalCard`, `SummaryChart`, `Insights`, `WeeklyBreakdown`
- mockData.ts — weekly/monthly sample data & goals
- metrics.ts, `utils/styles.ts`
- App.test.tsx, metrics.test.ts
- app.spec.ts
- Configs: vite.config.ts, tailwind.config.js, playwright.config.ts, postcss.config.js, `tsconfig*.json`, package.json
